# Mech Interp Workbench for VS Code

Your existing local course, notebooks, reading plan, papers, and progress inside VS Code.

Open the Mech Interp workspace and choose **Learning: Open Dashboard**, or click **Learning** in the status bar.
The Learning sidebar links to the plan, checklists, ARENA catalog, reading library, and your experiments.

The dashboard opens native notebooks with their existing Python environments. Research websites open in
VS Code's integrated browser. Local paper readers remember the same page as the JupyterLab readers.
Notes and checkmarks share the workspace's `progress.json`; notebook code and prose use Ctrl+S.

This extension is a local companion to this workspace. It has no hosted service, account, database, or
JavaScript runtime dependencies. Its source is in the workspace's `vscode-extension` folder.
